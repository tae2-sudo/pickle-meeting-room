2. 어떤 Google 데이터에 접근하나요

운영자가 본인 계정으로 직접 승인한 경우에만, 다음 목적과 범위 안에서 접근합니다.

  • YouTube Data API v3 (범위: youtube.force-ssl) — 운영자가 소유한 채널의 기본 정보(구독자 수, 총 조회수, 영상 수), 영상 목록·제목·공개 상태·조회수·좋아요·댓글 수, 채널 댓글과 답글. 대시보드에 표시하고, 운영자가 요청할 때 댓글 답글을 작성하기 위해서입니다.
  • YouTube Analytics API (범위: yt-analytics.readonly) — 운영자 채널의 조회수·시청 시간 등 분석 지표(읽기 전용).

Gmail, Google Drive, 연락처, 위치 등 다른 Google 데이터에는 접근하지 않습니다.

3. 어떻게 사용하고 보관하나요

  • 수집한 데이터는 운영자 본인의 채널 성과 확인과 관리 목적으로만 사용합니다.
  • OAuth 승인 토큰(리프레시 토큰)과 채널 통계 캐시는 운영자가 관리하는 Supabase 데이터베이스(서울 리전)와 운영자 기기에 저장됩니다. 저장소는 비공개이며 서비스 키는 서버 측 환경변수로만 보관합니다.
  • 통계 캐시는 대시보드 표시용이며 최신 값으로 계속 갱신됩니다.

1. What this service is

This is the privacy policy for a private dashboard and automation tool built by one individual to view and manage the performance of YouTube channels they own and operate. There is no public sign-up and no general users; it is used only with the owner's own Google account.

2. Which Google data is accessed

Only after the owner grants access with their own account, and only for the purposes below.

  • YouTube Data API v3 (scope youtube.force-ssl) — basic channel information for channels the owner owns (subscribers, total views, video count); video list, titles, privacy status, views, likes and comment counts; channel comments and replies. Used to display the dashboard and, when the owner asks, to post a reply to a comment.
  • YouTube Analytics API (scope yt-analytics.readonly) — read-only analytics metrics such as views and watch time for the owner's channels.

No other Google data (Gmail, Google Drive, contacts, location, etc.) is accessed.

3. How data is used and stored

  • Data is used solely for reviewing and managing the owner's own channel performance.
  • OAuth tokens (refresh tokens) and cached channel statistics are stored in a private Supabase database (Seoul region) managed by the owner, and on the owner's devices. Service keys are kept only as server-side secrets.
  • Cached statistics exist only to render the dashboard and are continuously refreshed.

4. No sharing, sale or advertising

  • Google user data is not shared, sold or rented to third parties.
  • It is not used for advertising, marketing or profiling, and no advertising trackers are used.
  • Google user data is not used to train generalized AI/ML models.
  • Only the owner accesses the data; no one else reviews it except when required for security or by law.

5. Google API Services User Data Policy

This service's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

6. Retention and deletion

  • Tokens and stored statistics are kept only while needed to run the service and are deleted promptly on request.
  • To request deletion, email love1004kl@gmail.com; stored tokens and data are deleted and the deletion confirmed, normally within 7 business days.
  • Access can be revoked at any time at Google Account → Security → Third-party apps & services; after revocation no further data is accessed.

7. Security

All traffic is encrypted over HTTPS. The client secret and refresh tokens are never placed in public repositories and are stored only as server-side secrets. Access is limited to the single owner.

8. Children

This service is not directed to children and does not knowingly collect children's personal information.
