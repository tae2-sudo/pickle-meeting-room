# 비서 통합 회의실 · Pickle Meeting Room

여러 AI 비서(Pickle)의 **남은 사용량**과 **대화**를 한 화면에서 관리하는 모바일 우선 웹앱입니다.
빌드 도구 없이 순수 HTML/CSS/JS 로 만들어졌고, GitHub Pages 에서 바로 열립니다.

> 이 저장소는 데모 앱입니다. API 키, 토큰, 전화번호, 이메일 등 개인 정보는 포함되어 있지 않습니다.
> 모든 데이터는 사용자의 브라우저 `localStorage` 에만 저장되며 서버로 전송되지 않습니다.

## 기능

- **상단 바** — 회의실 이름, 실시간 메시지 수 · 온라인 인원, 멤버/검색/설정/더보기
- **사용량 요약 바** — `위험 · 임박 · 정상 · 미확인` 카운트와 마지막 갱신 시각, 접기/펼치기
- **비서 사용량 대시보드** — 일일/주간 2열 카드, 남은 %, 색상 게이지, 상태 배지, 리셋 카운트다운,
  마지막 보고 시각, 추가 크레딧 태그, `잔여 입력` 편집 모달
- **그룹 채팅** — 메시지·시간·`@멘션` 하이라이트, 날짜 구분선, 검색 필터, localStorage 저장
- **작성창** — 빠른 작업 칩(회의 정리·할 일 뽑기·초안 써기), `@전체`/비서 멘션 칩,
  `+` 초대 모달(초대 문구 복사), 자동 높이 입력창, 음성 입력, 노란 전송 버튼
- **설정** — 회의실 이름, 위험/임박 기준, 갱신 기준 시간, 자동 응답, 비서 관리, JSON 내보내기/가져오기
- **PWA** — 홈 화면에 설치하면 앱처럼 실행(standalone), 오프라인 캐시 지원

## 로컬에서 보기

```bash
python3 -m http.server 8080
# http://localhost:8080
```

## GitHub Pages 배포

`main` 브랜치 루트(`/`)를 그대로 배포합니다. 별도 빌드 단계는 없습니다.

- 저장소: <https://github.com/tae2-sudo/pickle-meeting-room>
- 라이브: <https://tae2-sudo.github.io/pickle-meeting-room/>

## 데이터

- 저장 위치: `localStorage` 키 `pickle-meeting-room.v1`
- 백업/복원: `⋯ → JSON 내보내기 / 가져오기`
- 초기화: `⋯ → 데모 초기화`

## 파일 구성

```
index.html            화면 마크업
styles.css            모바일 우선 스타일
app.js                상태 관리 · 렌더링 · 이벤트 (의존성 없음)
manifest.webmanifest  PWA 매니페스트
sw.js                 오프라인 서비스 워커
icons/                앱 아이콘 (192/512/maskable)
```
